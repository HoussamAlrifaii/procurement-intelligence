# Reference data

Small lookup tables maintained by hand and committed to the repository.

| File | Content | Source |
|---|---|---|
| `cpv_divisions.csv` | The 45 divisions (first two digits) of the Common Procurement Vocabulary, with their names | CPV 2008, Commission Regulation (EC) No 213/2008 |
| `countries.csv` | Names of the 33 buyer countries in the TED data, keyed by the codes TED uses (`UK` for the United Kingdom, `GR` for Greece) | ISO 3166-1 country names |
